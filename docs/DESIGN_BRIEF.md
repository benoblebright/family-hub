# 가족 안부 허브 — 디자인 브리프

다른 디자인 도구(Figma, Stitch, v0 등)에 넘기기 위한 요약. 배포본: https://family-hub-eight-mu.vercel.app

## 1. 서비스 한 줄

혼자 사는 부모님(2G폰)과 따로 사는 형제·가족·친구를 잇는 월구독 안부 서비스. 부모님은 지금 쓰는 문자·전화만 쓰고, 가족은 링크로 들어오는 모바일 웹 "가족방"에서 함께 본다. 슬로건: **"엄마가 먼저 묻는 가족방"**.

## 2. 사용자와 톤

| 사용자 | 기기 | 이 화면에서 하는 일 |
|---|---|---|
| 함께하는 사람 (자녀 30~50대, 형제·가족·친구) — 주 사용자 | 스마트폰, 카톡 링크로 진입 | 엄마 안부 확인, 엄마 질문에 답장, "통화했어요" 기록, 우체통에 소식 남기기 |
| 부모님 | 2G폰 (웹을 쓰지 않음) | 화면 안에서는 "엄마 폰 시뮬레이터"로만 등장 |
| 운영자 | PC·모바일 | 가족 등록, 통화 기록, KPI |

- 톤: 따뜻하고 차분함, 믿음직함. **감시·응급·관제처럼 보이면 안 됨** (위급상황 대응은 약속하지 않는 서비스).
- 문구: 존댓말 "~해요"체, 짧게. 사람은 "함께하는 사람 / 모두"로 부른다(형제만 대상처럼 보이지 않게).
- 핵심 지표가 "가족이 엄마께 직접 건 통화 수"라서, **"통화했어요" 행동이 가장 눈에 띄어야** 한다.

## 3. 화면 구조 (정보 구조)

```
소개 (상단 앱 바: 로고 · "가족방 만들기")
├─ /            랜딩
├─ /start       가족방 만들기
└─ /demo        데모 사람 고르기

가족방 /f/[내 링크]  (상단 앱 바: 가족방 이름 + 내 호칭·이름 · 설정 아이콘 / 하단 탭 5개)
├─ 홈           /f/[토큰]
├─ 질문         /f/[토큰]/questions  → 답장 /f/[토큰]/q/[질문]
├─ 우체통       /f/[토큰]/mailbox
├─ 가족신문     /f/[토큰]/news
├─ 엄마 폰      /f/[토큰]/sim   (체험용 시뮬레이터)
└─ 설정         /f/[토큰]/settings (앱 바 아이콘)

운영자 /admin  (별도 상단 바 "운영자" · 상단 칩 메뉴: 전체 / +가족 등록 / 가족 운영 / ARS 대본)
├─ /admin, /admin/new, /admin/f/[가족], /admin/f/[가족]/ars, /admin/login
```

## 4. 화면별 구성 요소

### 랜딩 `/`
1. 히어로: 칩("형제·가족·친구가 함께 구독 · 첫 달 무료"), 제목, 설명 2줄, 주 버튼 "지금 우리 가족방 만들기"
2. "어떻게 시작할까요?" 진입 카드 3개 (아이콘 + 제목 + 설명 + ›): 가족방 만들기 / 데모 가족방 둘러보기 / 엄마 폰 체험하기
3. "이렇게 돌아가요" 3단계 (아이콘 원 + 제목 + 설명)
4. 인용 카드: "큰애 토요일 오전, 딸 일요일 점심, 막내는 아직 답이 없어요."
5. 요금제 카드 3개: 베이직 9,900 / 스탠다드 16,900(강조, "가장 많이 선택") / 프리미엄 29,900 — 가격, "3명이 나누면 1인 ○원", 체크 목록
6. 첫 달 무료 신청 폼 (이름, 연락처, 함께할 사람 수, 부모님 전화 종류, 요금제, 메모, 개인정보 동의)
7. 자주 묻는 질문 4개, 푸터 링크

### 가족방 만들기 `/start`
카드 3개로 나눈 폼: ① 부모님(호칭, 아침 안부 문자 시각, 전화번호, 전화 종류) ② 나(이름, 호칭) ③ 함께할 사람 3줄(이름, 호칭) → "가족방 만들기"

### 가족방 공통
- 상단 앱 바: 집 아이콘 + 가족방 이름(굵게) / 아래 작은 글씨 "큰아들 민수" · 오른쪽 설정 아이콘
- 하단 탭 5개(Material 3 navigation bar): 홈 · 질문(안 읽은 수 배지) · 우체통 · 가족신문 · 엄마 폰. 선택된 탭은 알약 모양 표시

### 홈 (위에서부터)
1. 날짜 + "민수님, 엄마 이번 주 소식이에요"
2. 초대 카드(접힘): 함께할 사람별 링크 + "초대 문구 복사"
3. 알림 카드(주황, 종 아이콘): "엄마께서 오늘 안부 문자와 확인콜에 모두 답이 없으세요…" + 시각
4. 오늘 엄마 안부 카드: 상태 칩(좋아/그냥/별로/확인콜로 확인/응답 없음/내일 09:00 문자 예정) + **4주 응답 캘린더**(7열 격자, 칸마다 날짜 + 아이콘: 웃는 얼굴 초록 / 보통 얼굴 파랑 / 찡그린 얼굴 주황 / 전화 아이콘 / 부재중 아이콘) + 범례 + "최근 7일 중 6일 응답"
5. 엄마 질문 카드(열린 질문이 있을 때): 말풍선 모양 질문 + 마감까지 남은 시간 → 질문 탭으로
6. AI 안부콜 주간 요약: 3줄 + 기분 칩 + "안부콜 3번 중 2번"
7. 이번 주 엄마께 물어볼 것: 번호 목록 3개
8. 이번 주 누가 통화했나: 사람별 줄(동그라미 첫 글자 아바타, 호칭, 마지막 통화·메모, 횟수 칩) + **"엄마랑 통화했어요" 초록 버튼** → 누르면 메모 입력 + "기록하기"

### 질문 탭 / 답장 화면
- 질문 탭: "답할 질문" 카드들(질문 말풍선, 마감 칩, "3명 중 1명 답함", 답장하기 버튼), "지난 질문" 목록(질문 + → 요약 문자), 빈 상태 일러스트·문구
- 답장: 질문 말풍선(누가 어떻게 남겼는지), 모두의 답장 목록(아바타 + 답 + 답함/대기 칩), 내 답장 폼: **빠른 답 선택 칩 2열**(예: 토요일/일요일/월요일/못 가요), 메모 입력, "엄마께 목소리로 답하기" 녹음 버튼(녹음 중 빨간 점 + 초), "메모는 엄마께는 빼줘" 체크, 보내기. 마감 후엔 "엄마께 전해드린 내용"(문자 45자 + 전화로 읽어드린 문장)

### 우체통
"소식 남기기"(음성 녹음 버튼 + 글 입력 + 우체통에 넣기) / "남긴 소식" 목록(누가, 언제, 글·음성 플레이어, 대기·들으심 칩)

### 가족신문
종이 신문 미리보기(A4, 세리프 느낌 제호 "엄마네 가족방 소식", 호수, 섹션: 이달의 엄마 / 엄마의 옛날 이야기 / 가족방에서 보낸 편지 / 이달의 엄마 질문 / 통화 횟수) + 지난달 버튼 + 인쇄 버튼. 큰 글씨(어르신이 종이로 읽음)

### 엄마 폰 시뮬레이터
1. 가상 시각 카드: "10월 22일 (목) 09:01", "실제보다 1일 2시간 앞", 버튼 +30분 / +2시간 / **다음 안부 문자(09:00)** / 지금으로
2. **2G폰 목업**: 어두운 폰 테두리, 상단 상태 표시(시각·신호·배터리), 연녹색 문자 화면(받은 문자 흰 말풍선 왼쪽, 보낸 문자 노란 말풍선 오른쪽, 시각), 걸려오는 전화 화면(받기 초록 / 거절), 숫자 키 1·2·3(좋아·그냥·별로), 글 입력 + 전송
3. "이렇게 동작해요" 번호 목록, 이벤트 로그(종류 칩 + 시각 + 내용)

### 설정
"알림 받기 편한 시간" 입력, 주간 요약 알림·질문 알림 체크, 저장

### 운영자 (밀도 높은 관리 화면, 모바일·PC 겸용)
KPI 카드 2열(가족 수·월 매출·엄마께 건 통화·새 신청), 확인할 가족, 가족 목록, 신청자 목록 / 가족 운영: 통화 기록 입력 폼(종류, 시각, 받음, 분, 기분, 요약, 플래그 체크, 기억 노트, 엄마 질문, 회상 이야기), 엄마 질문 목록과 마감, 주간 요약 발행, 기억 노트, 회상 이야기, 동의 기록, 링크·알림톡 문구 / ARS 대본: 말풍선(읽을 말)과 회색 지시문

## 6. 디자인 도구에 요청할 것 (제안)

1. 위 토큰을 출발점으로 한 **컬러·타이포 시스템** (브랜드 색을 블루로 유지할지, 따뜻한 계열로 갈지 2안)
2. 핵심 화면 4개 시안: **랜딩, 가족 홈, 답장, 엄마 폰 시뮬레이터** (375px 모바일, 라이트·다크)
3. 컴포넌트: 카드, 알약 버튼(주/보조/초록), 칩, 선택 칩, 하단 탭, 알림 카드, 응답 캘린더 칸 6종, 사람 줄(아바타+칩), 질문 말풍선, 2G폰 목업
4. 빈 상태·로딩·완료(초록 안내) 상태
5. 로고/브랜드 마크 (지금은 Material 아이콘 "family_home")

## 7. 구현 쪽 제약 (디자인 결과를 받을 때)

- Next.js 15 + 일반 CSS(`src/app/globals.css`) — Tailwind·UI 라이브러리를 쓰지 않음. 시안은 **색·크기·간격 값**과 컴포넌트 상태로 받으면 그대로 옮길 수 있다.
- 주요 클래스: `.card .btn(.secondary .small .ok) .tag(.ok .warn .gray) .choice .question .avatar .alert-card .cal .day .bottomnav .tab .appbar .phone .bubble .key .entry .hero .plan .kpi .paper`
- 글씨 위주의 한국어 화면이라 줄바꿈은 단어 단위(`word-break: keep-all`). 버튼 문구가 두 줄로 꺾이지 않게 여유 폭 필요.
- 아이콘은 Material Symbols 이름으로 지정(예: `call`, `forum`, `markunread_mailbox`, `newspaper`, `smartphone`, `sentiment_satisfied`, `phone_missed`).
