# 가족 안부 허브 — 요구사항 정의

## 1. 문제 정의

혼자 사는 고령 부모님(특히 2G폰 사용자)과 따로 사는 가족들 사이의 연락은 "누가 언제 전화했는지" 모른 채 한두 명에게 몰리거나 끊기기 쉽다.
기존 AI 안부콜(지자체 클로바 케어콜 등)은 **기관 → 부모님 단방향 확인**이라, 자녀들의 실제 연락을 늘리지 못하고 부모님이 먼저 말을 걸 통로도 없다.

**목표:** 부모님은 지금 쓰는 전화(문자·통화)만으로, 가족들은 링크 하나로 참여하는 "엄마가 먼저 묻는 가족방"을 만든다.
핵심 지표는 **가족들이 엄마께 직접 통화한 횟수**다.

## 2. 사용자

| 사용자 | 환경 | 하는 일 |
|---|---|---|
| 부모님 | 2G폰, 문자·전화만 | 아침 안부 문자에 숫자로 답, 자녀들에게 질문 보내기, 답 듣기 |
| 가족 구성원 (형제·가족·친구) | 스마트폰, 카톡 링크 | 주간 요약 보기, 엄마 질문에 답장, "통화했어요" 기록, 우체통에 소식 남기기 |
| 운영자 | PC | 가족 등록, 통화 기록, 질문 마감, 주간 요약 발행 |

## 3. 화면과 기능 요구사항

평가자가 URL로 직접 써볼 수 있도록 실제 문자·전화 대신 **엄마 시뮬레이터(2G폰 화면)**로 재현한다.
시간 흐름은 시뮬레이터의 **시간 빨리감기** 버튼으로 재현한다. 모든 날짜·시각은 **한국 시간(KST)** 기준이다.

### ① 랜딩 (`/`)
- R1-1 서비스 소개, 요금제 3종(24,900 / 39,900 / 59,900원)을 보여준다.
- R1-2 이름·연락처·함께할 사람 수·부모님 전화 종류·요금제를 입력하면 대기 신청이 저장되고 완료 문구가 나온다.
- R1-3 개인정보 동의를 체크하지 않거나 연락처가 숫자 형식이 아니면 저장되지 않고 안내 문구가 나온다.
- R1-4 "가족방 만들기"로 바로 체험할 수 있다.

### ② 가족방 만들기 (`/start`)
- R2-1 부모님 호칭·전화번호·안부 문자 시각(예: 09:00)과 함께할 사람 이름·호칭을 입력하면 가족방이 만들어진다.
- R2-2 한 명마다 전용 초대 링크(토큰)가 만들어지고, 복사할 수 있는 초대 문구가 나온다.
- R2-3 만든 사람은 바로 자기 가족 홈으로 이동한다.

### ③ 엄마 시뮬레이터 (`/f/[토큰]/sim`)
- R3-1 안부 문자 시각이 되면 엄마 폰에 "오늘 기분은? 1 좋아 2 그냥 3 별로" 문자가 온다.
- R3-2 엄마가 1·2·3으로 답하면 그날 응답이 기록되고 가족 홈 캘린더에 표시된다.
- R3-3 **2시간 안에 답이 없으면 재문자**가 발송된다.
- R3-4 재문자 후 **1시간 안에도 답이 없으면 AI 확인콜**이 걸린다(시뮬레이터에 수신 화면).
- R3-5 확인콜을 받으면 "통화로 확인"으로 기록되고, 받지 않으면 **가족 전원에게 알림**이 기록된다.
- R3-6 엄마가 **3(별로)**로 답하면 가족 전원에게 "전화 한 통 어떠세요" 알림이 기록된다.
- R3-7 엄마가 숫자가 아닌 글을 보내면 **가족들에게 질문**으로 열린다.
- R3-8 질문이 마감되면 엄마 폰에 **45자 이내 요약 문자**가 온다.
- R3-9 모든 발송·수신·알림은 이벤트 로그에 시각과 함께 남는다.

### ④ 가족 홈 (`/f/[토큰]`)
- R4-1 최근 4주 엄마 응답 캘린더(좋아/그냥/별로/통화 확인/무응답)를 보여준다.
- R4-2 엄마 질문에 빠른 답 버튼·글·음성으로 답장할 수 있고, "엄마께는 빼줘"를 고르면 그 메모는 요약에서 빠진다.
- R4-3 **가족 전원이 답하거나 마감 시각이 지나면** AI가 엄마용 요약(문자 45자 이내 + 전화용 문장)을 만든다. 답이 없는 사람은 지어내지 않고 "아직 답 없음"으로 쓴다.
- R4-4 "엄마랑 통화했어요"를 누르면 이번 주 사람별 통화 횟수에 반영된다.
- R4-5 엄마 우체통에 글·음성을 남길 수 있다.
- R4-6 가족 알림(별로 응답, 확인콜 미응답)이 가족 홈 상단에 보인다.

## 4. 비기능 요구사항
- N1 API 키·서비스 계정 키는 서버 환경변수에만 두고 브라우저로 보내지 않는다.
- N2 Firestore·Storage 보안 규칙은 브라우저 직접 읽기·쓰기를 모두 막고, 서버(firebase-admin)만 접근한다.
- N3 서버리스(Vercel)에서도 데이터가 유지되도록 파일이 아닌 Firestore에 저장한다.
- N4 모바일 375px 폭에서 가로 스크롤 없이 쓸 수 있다.
- N5 Claude API 키가 없거나 호출이 실패해도 규칙 기반 요약으로 동작한다.

## 5. 기술 구성
- Next.js 15 (App Router, 서버 액션) + Vercel 배포, GitHub 연동
- Firebase Firestore(asia-northeast3 서울) + Cloud Storage(음성), firebase-admin
- Claude API (질문 분류, 답장 요약)
- 로컬 개발: Firebase 키가 없으면 `data/db.json` 파일 저장소로 동작
